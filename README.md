# Ridam Grover — High-Craft Editorial Portfolio & Freelance Platform

A bespoke, production-ready personal portfolio and client acquisition platform for **Ridam Grover** — Full-Stack Engineer & Freelance Developer. Built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **GSAP ScrollTrigger**, **Lenis Smooth Scroll**, and **Cormorant Garamond / Plus Jakarta Sans** luxury editorial typography.

Inspired by award-winning editorial web design (Sarthak Sharma portfolio aesthetic) with dark obsidian contrast, subtle architectural gridlines, and bespoke typography.

---

## 🚀 Getting Started

```bash
# Clone & Install
git clone https://github.com/ridamgrover/ridam-portfolio.git
cd ridam-portfolio
npm install

# Run the development server
npm run dev

# Run ESLint validation
npm run lint

# Build production bundle
npm run build
```
